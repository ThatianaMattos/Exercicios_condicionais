# Exercicios_condicionais

Exercícios de Condicionais com DOM

Prática dos conceitos de condicionais em JavaScript aplicados diretamente no DOM.
Exercícios feitos durante o Vai na Web Empower para treinar lógica, manipulação de elementos e tomada de decisão no código.

Tecnologias usadas

HTML

CSS

JavaScript

DOM (Document Object Model)

O que foi praticado

Leitura e modificação de elementos com textContent

Alteração de estilos via style

Uso de condicionais if, else if, else

Operadores de comparação e lógicos

parseInt() e parseFloat()

Troca dinâmica de imagens e temas

Exercícios
1.Cor da caixa conforme o texto

Ler o texto dentro de uma div e mudar sua cor dependendo do conteúdo.

2.Mostrar ou esconder mensagem

Exibir uma mensagem no DOM apenas se uma variável booleana for verdadeira.

3.Verificar idade e alterar texto

Ler a idade da tela, converter para número e exibir se a pessoa é maior ou menor de idade.

4.Mudar tema da página

Aplicar tema claro ou escuro conforme o valor de uma variável.

5.Nota do aluno

Ler a nota exibida, converter para número e mostrar se o aluno está aprovado, em recuperação ou reprovado.

6.Produto em promoção

Comparar o preço exibido com um valor base e colorir o texto conforme a condição.

7.Avatar do usuário

Trocar a imagem exibida conforme o status (online ou offline).

Como rodar

Baixe o repositório

Abra a pasta no VS Code

Use a extensão Live Server (ou abra o HTML no navegador)

Teste cada exercício alterando os valores no HTML ou JS e observando o resultado

Status

Todos os exercícios finalizados com sucesso.
